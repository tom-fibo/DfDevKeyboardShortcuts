This is a Minecraft mod designed for use within the [DiamondFire](https://mcdiamondfire.com/) server's dev mode that allows easy access to all needed blocks by binding placing each specific block to a different key on the keyboard (rather than managing all of them in your inventory).

It was mostly written by hand, with AI assistance (e.g. getting the Fabric function to interact with Minecraft in a specific way), although updating to 26.2 (where all Minecraft-based method signitures changed significantly) relied on AI use.
